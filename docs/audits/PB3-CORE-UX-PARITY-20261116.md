## Что исправлено

В основной сборке поведение было подключено к разметке, отличавшейся от утверждённых HTML. Восстановлены исходные каскады CSS, SVG и структура Welcome 1.4, Welcome Loading 1.6, PIN 1.1, Camera, Browser v3, File Viewer и Public Card 1.1. Источники: `docs/ux/`, контракт `docs/ux/UI-SHELL-CONTRACT.md`. Все 117 исходных файлов сверены по Git blob и длине, исходники не редактировались. `ts.md` не изменён.

Header/Dock, размеры, отступы, иконки, список/сетка/дерево, путь, панели действий, увеличение фото и публичной карточки перенесены в живые Vue-компоненты. Расширенные операции доступны через настоящие меню; E2EE, серверные ACL, подписанная политика заданий и реальный Garage сохранены. На низких экранах PIN и Viewer прокручиваются вместо потери элементов. Длинная публичная карточка прокручивается до footer. При отзыве публикации открытый lightbox тоже очищается.

Обнаружен и исправлен реальный race импорта: сравнение Session по ссылке отменяло AES-GCM операцию после online hydration того же устройства. Новый guard допускает замену оболочки Session при тех же account/device и тех же объектах ключевого пакета/device envelope. Смена аккаунта, устройства, ключей и logout по-прежнему отменяют операцию. Проверка повторяется до и после записи внутри IndexedDB transaction. Добавлены семь регрессий, включая реальную расшифровку и rollback при смене идентичности во время записи. Регрессия сначала воспроизведена RED (`identity.account_changed`, exit 1), затем 14/14 тестов этого модуля PASS.

## Проверяемое визуальное соответствие

Evidence: [каталог](evidence/PB3-UX-PARITY-20261116/), [geometry.json](evidence/PB3-UX-PARITY-20261116/geometry.json), [pixel-comparison.json](evidence/PB3-UX-PARITY-20261116/pixel-comparison.json).

Chromium, deviceScaleFactor 1, reduced motion; 375×812, 390×844, 1280×800. Проверена собранная Docker-версия, не только Vite. 11 состояний × 3 размера = 33 пары скриншотов. 228 элементов × четыре координаты = 912 точных сравнений, допуск 0; PASS. Welcome, Loader, PIN: 9 полных пар, 0 отличающихся RGBA-пикселей; PASS.

Для динамических экранов исходные демонстрационные метаданные заменены равными фактическими данными теста; из reference удалены лишние демонстрационные записи. У публичной фотографии нормализовано соотношение сторон. CSS эталонов не менялся; удалена только внешняя рамка preview и toolbar. Секретный URL карточки замаскирован. Динамические фото/видео не объявляются побайтно равными демонстрационным SVG. Геометрическая проверка не доказывает идентичность каждого непроверенного состояния интерфейса.

Визуальный сценарий создаёт настоящую identity, снимает JPEG через Chromium MediaStream, сохраняет AES-GCM ciphertext, синхронизирует с PostgreSQL/Garage, открывает публичную карточку и устанавливает настоящий PIN. Loader удерживается реальной ограниченной read-only-in-effect IndexedDB transaction, а не подменой состояния компонента.

## Ограничения

Native Safari 26.6.2 установлен. Запуск локального safaridriver отклонён автоматической проверкой разрешений: потенциальное расширение доступа к браузеру требует отдельного разрешения владельца. Драйвер не запускался, Allow Remote Automation не менялся. Native Safari — NOT TESTED. Физические iOS/Android, реальные GPS и камера телефона — NOT TESTED; Chromium fake MediaStream не заменяет hardware.

Cold-offline bootstrap / подписанный SW — BLOCKED BY DESIGN до независимого trust anchor; неподписанный Service Worker не включён. Emergency/Panic destruction остаётся feature-gated: полного verified Recovery Vault pipeline эта поставка не добавляет. Matrix автоматически не подключался. Реальная оплата, все остальные страницы PB3 и все состояния редакторов не входят в заявление о визуальном соответствии семи core экранов.
