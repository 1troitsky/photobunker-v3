## What is real in this slice

1. One pure \`resolveBrand\` contract is consumed both in the Vue runtime (Shell, Help) and Vite build (PWA metadata), avoiding accidental split defaults.
2. The initial HTML title, favicon and theme-color are rewritten during both Vite development and production builds. Product name is HTML-escaped and the icon path is same-origin and path-traversal resistant.
3. PWA installation manifest uses the same name, short name, color and icon. The icon must actually exist inside \`apps/web/public/icons\`; missing assets fail the build rather than emit broken install metadata.
4. The public URL is validated as a clean HTTPS origin (or local HTTP loopback), but is **not** yet used to publish unauthorised public links. APP_SLUG is validated without renaming stable internal IDs.
5. Unit tests cover a renamed test brand, HTML escaping, unsafe public URL schemes/credentials/queries, external or traversal icon paths, bad color/slug, and loopback development.
